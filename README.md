# Meus Jogos

App (PWA) para registrar jogos que você terminou: nota, data e prints. Capas automáticas da Steam.

## Publicar no GitHub Pages
1. Crie um repositório e envie todos estes arquivos para a raiz.
2. Settings → Pages → Source: "Deploy from a branch" → `main` / `(root)` → Save.
3. Abra `https://SEU-USUARIO.github.io/NOME-DO-REPO/` no Chrome do celular.
4. Menu ⋮ → "Instalar app" (ou "Adicionar à tela inicial"). No iPhone: Safari → Compartilhar → "Adicionar à Tela de Início".
